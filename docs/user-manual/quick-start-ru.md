# Code Print Manager — Краткое руководство

Это руководство проведёт вас через первоначальную настройку: установку приложения, добавление принтера, создание продукта, импорт кодов и запуск первого задания печати.

Подробную информацию обо всех функциях см. в [Полном справочном руководстве](manual-ru.md).

---

## 1. Установка и запуск

1. Запустите **CodePrintManager-win-Setup.exe**
2. Запустите **Code Print Manager** из меню «Пуск»

Это всё. Права администратора не нужны, дополнительное программное обеспечение не требуется, и приложение будет обновляться самостоятельно.

**Требования:** Windows 10 или 11 (64-разрядная), 2 ГБ оперативной памяти, 500 МБ свободного места на диске.

При первом запуске приложение автоматически создаёт свою базу данных и файлы журналов. Вы увидите экран «Панель управления» без данных. О том, где хранятся эти файлы, см. [Резервное копирование данных](manual-ru.md#резервное-копирование-данных).

---

## 2. Добавление принтера

Ваш принтер Savema должен быть подключён к той же сети и включён.

1. Нажмите **Принтеры** в боковом меню слева
2. Нажмите **+ Добавить принтер**
3. Заполните:
   - **Имя** — понятное название (например, «Линия 1»)
   - **IP-адрес** — сетевой адрес принтера (например, 192.168.1.100)
   - **Порт** — 9100 (стандарт для принтеров Savema)
4. Нажмите **Сохранить**

Приложение подключается к принтеру автоматически. Зелёный индикатор означает, что подключение прошло успешно.

```
┌─────────────────────────────────────────────────────────────┐
│  ПРИНТЕРЫ                               [+ Новое задание]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [ Линия 1 ▼ ]  192.168.1.100  ● ОЖИДАНИЕ                 │
│                                                             │
│  [Конфигурация]  [Хранилище]                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

> **Совет:** Чтобы протестировать без реального принтера, запустите приложение из командной строки:
> `CodePrintManager.exe --mock`

## 3. Создание продукта

Продукты — это то, на что вы наносите коды (например, «Яблочный сок 0.5л»).

1. Нажмите **Продукция** в боковом меню слева
2. Нажмите **+ Продукт** вверху дерева
3. Введите название продукта и нажмите **Сохранить**
4. На вкладке **Настройки** справа:
   - Укажите **Файл шаблона** — выберите ваш файл `.rox`
   - Укажите **Имя CSV для принтера** — имя файла, которое будет использоваться принтером (например, `apple_05.csv`)
   - Нажмите **Сохранить**

```
┌─────────────────────────────────────────────────────────────┐
│  ПРОДУКЦИЯ                                                   │
├────────────────┬────────────────────────────────────────────┤
│ [+ Папка]      │  ЯБЛОЧНЫЙ СОК 0.5Л                        │
│ [+ Продукт]    │                                            │
│                │  [Операции]  [Настройки]  [Коды]          │
│  ● Яблочный    │                                            │
│    сок         │  Файл шаблона: apple_05_53.rox            │
│    0.5л  ←     │  Имя CSV для принтера: apple_05.csv       │
│                │                                            │
└────────────────┴────────────────────────────────────────────┘
```

> **Совет:** Используйте **+ Папка** для группировки продуктов (например, по бренду или линейке). Папки служат только для организации — печать идёт с продуктов, а не с папок.

---

## 4. Импорт кодов

Коды поступают из CSV-файлов, скачанных с государственного портала. Каждый код используется строго один раз во всей системе.

1. Выберите ваш продукт в дереве
2. На вкладке **Операции** нажмите **Импорт CSV...**
3. Выберите CSV-файл и откройте его
4. Приложение проверит файл и покажет результат

После импорта вы увидите количество кодов в разделе **Пул кодов**:

```
  Пул кодов:
    Доступно:     10 000
    Напечатано:   0
    Всего:        10 000
```

Приложение проверяет каждый код на дубликаты. Если какой-либо код уже существует в системе (в любом продукте), он будет отклонён, и вы получите уведомление.

## 5. Первая печать

1. Нажмите **+ Новое задание** (доступно на страницах «Панель управления», «Продукция», «Принтеры» или «Задания»)
2. Выберите **Продукт** из выпадающего списка
3. Выберите **Принтер** из выпадающего списка
4. Введите **Количество** (число кодов для печати)
5. Нажмите **Подготовить**

```
┌─────────────────────────────────────────────────────────────┐
│  НОВОЕ ЗАДАНИЕ                                  [← Назад]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Продукт:    [ Яблочный сок 0.5л   ▼ ]  (10 000 доступно) │
│  Принтер:    [ Линия 1            ▼ ]  (● ожидание)       │
│  Количество: [ 500                   ]                     │
│                                                             │
│              [Подготовить]                                  │
│                                                             │
│  ── Ход подготовки ──────────────────────────────────────── │
│  ✓ Состояние принтера проверено                            │
│  ✓ 500 кодов зарезервировано из пула                       │
│  ✓ Файл данных загружен на принтер                         │
│  ✓ Шаблон успешно активирован                              │
│                                                             │
│  ✅ Задание #1 готово к печати.                             │
│                                                             │
│              [Начать печать]  [Перейти к заданию]           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

6. Когда подготовка завершится, нажмите **Начать печать**

Приложение перенесёт вас на Панель управления, где вы сможете наблюдать за прогрессом в реальном времени:

```
┌─────────────────────────────────────────────────────────────┐
│  Линия 1  192.168.1.100                        ● ПЕЧАТЬ     │
│  Задание #1: Яблочный сок 0.5л   247/500 (49%)              │
│  █████████████████░░░░░░░░░░░░░░░░   [Пауза] [Отмена]      │
└─────────────────────────────────────────────────────────────┘
```

Когда все коды будут напечатаны, задание завершится автоматически.
