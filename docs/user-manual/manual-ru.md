## Страница 1: Обзор приложения

Code Print Manager — это настольное приложение для Windows, которое управляет печатью уникальных государственных кодов продукции (Data Matrix / QR) на термопринтерах Savema. Оно предотвращает повторное использование кодов, минимизирует потери, отслеживает каждый код от импорта до печати и безопасно восстанавливается после сбоев.

### Структура главного окна

```
┌─────────────────────────────────────────────────────────┐
│                    CODE PRINT MANAGER                    │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│    МЕНЮ      │          РАБОЧАЯ ОБЛАСТЬ                 │
│              │                                          │
│ Панель       │   (меняется в зависимости от             │
│  управления  │    выбранной страницы)                   │
│ Продукция    │                                          │
│ Принтеры     │                                          │
│ Задания      │                                          │
│              │                                          │
│ [Язык ▼]     │                                          │
├──────────────┴──────────────────────────────────────────┤
│ УВЕДОМЛЕНИЯ                                             │
└─────────────────────────────────────────────────────────┘
```

- **Боковое меню** — панель навигации. Нажмите на любой пункт для перехода.
- **Рабочая область** — основная зона, содержимое которой зависит от выбранной страницы.
- **Язык** — переключатель языка в нижней части бокового меню. Переключайтесь между русским, английским и армянским.
- **Панель уведомлений** — всегда видна в нижней части окна, независимо от того, на какой странице вы находитесь.

### Страницы навигации

| Страница | Назначение |
|----------|------------|
| **Панель управления** | Обзор всех принтеров и текущих заданий в реальном времени. Ваш основной экран мониторинга. |
| **Продукция** | Создание и организация продуктов, импорт кодов, управление пулами кодов. |
| **Принтеры** | Добавление и настройка принтеров, управление файлами на принтерах. |
| **Задания** | Просмотр активных заданий, история заданий. |

Кнопка **+ Новое задание** доступна на каждой странице. Она открывает экран создания задания.

### Уведомления

Панель уведомлений показывает оповещения в реальном времени:

- **Красные** — требуется немедленное действие (потеря соединения, ошибка задания). Остаются видимыми, пока вы их не закроете.
- **Жёлтые** — произошло что-то необычное, требуется проверка (неожиданная активность счётчика, мало кодов). Остаются видимыми, пока вы их не закроете.
- **Зелёные** — информационные (задание завершено, принтер подключён). Исчезают автоматически через 30 секунд.

Нажмите **X** на любом уведомлении, чтобы его закрыть.

## Страница 2: Настройка

### Добавление принтеров

Каждый принтер Savema в вашей сети должен быть зарегистрирован в приложении.

1. Перейдите на страницу **Принтеры**
2. Нажмите **+ Добавить принтер**
3. Заполните:
   - **Имя** — понятное название (например, «Производственная линия 1»)
   - **IP-адрес** — сетевой адрес принтера
   - **Порт** — 9100 (стандарт для термопринтеров Savema)
4. Нажмите **Сохранить**

Приложение подключается к принтеру автоматически. Индикатор состояния показывает:

| Состояние | Значение |
|-----------|----------|
| **Ожидание** (зелёный) | Подключён и готов к печати |
| **Печать** (синий) | В процессе печати |
| **Не в сети** (серый) | Нет подключения — проверьте сеть и питание |
| **Ошибка** (красный) | Проблема с принтером — проверьте дисплей принтера |
| **Заблокирован** (жёлтый) | Интерфейс принтера не на главном экране — вернитесь на главный экран принтера |
| **Инициализация** (серый) | Принтер запускается — подождите |

Приложение автоматически переподключается при потере связи. Вам не нужно ничего делать — оно продолжит попытки в фоновом режиме и уведомит вас о восстановлении связи.

### Создание продуктов

Продукты организованы в дерево, подобно папкам на компьютере.

- **Папки** — только для группировки (например, «Соки», «Вода»)
- **Продукты** — то, на что вы печатаете (например, «Яблочный 0.5л»)

```
▼ Соки
  ▼ Яблочный
    ● 0.5л        ← продукт (для печати)
    ● 1.0л        ← продукт (для печати)
  ▼ Апельсиновый
    ● 0.33л       ← продукт (для печати)
▼ Вода
  ● Негаз. 0.5л   ← продукт (для печати)
```

**Чтобы создать папку:** Нажмите **+ Папка**, введите название и сохраните.

**Чтобы создать продукт:** Нажмите **+ Продукт**, введите название и сохраните. Затем перейдите на вкладку **Настройки** и укажите:

- **Файл шаблона** — файл `.rox`, используемый принтером для этого продукта
- **Имя CSV для принтера** — имя файла данных на принтере (например, `apple_05.csv`)

> **Важно:** И файл шаблона, и имя CSV должны быть заданы, прежде чем вы сможете создать задание печати для этого продукта.

**Чтобы переименовать:** Щёлкните правой кнопкой мыши на продукте или папке и выберите **Переименовать**.

**Организация:** Элементы добавляются относительно того, что выбрано в дереве. Сначала выберите папку, затем нажмите **+ Продукт**, чтобы добавить продукт внутрь этой папки. Щёлкните по пустому месту, чтобы снять выбор и добавить элемент на верхний уровень.

### Импорт кодов

Коды импортируются из CSV-файлов (обычно скачанных с государственного портала).

1. Выберите продукт в дереве
2. На вкладке **Операции** нажмите **Импорт CSV...**
3. Выберите CSV-файл

Приложение проверяет каждый код:
- Пустые или некорректные коды отклоняются
- Коды, уже существующие в системе (в любом продукте, в любом статусе), отклоняются как дубликаты
- Подробный отчёт показывает, сколько кодов импортировано и сколько отклонено

После импорта раздел **Пул кодов:** покажет обновлённые данные. На вкладке **Операции** также отображается единая история активности, показывающая импорты и результаты заданий в хронологическом порядке.

> **Важно:** Каждый код должен быть уникальным во всей системе. Вы не можете импортировать один и тот же код в два разных продукта. Это основная гарантия безопасности, предотвращающая двойную печать.

### Резервное копирование данных

Приложение хранит все данные в локальной базе. Для резервного копирования скопируйте эти три файла из папки приложения:

- `codeprintmanager.db`
- `codeprintmanager.db-shm` (если существует)
- `codeprintmanager.db-wal` (если существует)

Для восстановления скопируйте их обратно. Убедитесь, что приложение закрыто.

## Страница 3: Печать

### Создание задания печати

Задание печати связывает три вещи: **продукт** (какие коды печатать), **принтер** (на каком аппарате) и **количество** (сколько кодов).

1. Нажмите **+ Новое задание** (доступно на любой странице). Если вы нажали на странице «Продукция», продукт будет предвыбран. Если на странице «Принтеры» — принтер будет предвыбран.
2. Выберите **Продукт** — в выпадающем списке показано количество доступных кодов
3. Выберите **Принтер** — в выпадающем списке показано состояние принтера (занятые или отключённые принтеры выделены серым)
4. Введите **Количество**
5. Нажмите **Подготовить**

**Что происходит во время подготовки:**

Приложение выполняет несколько проверок и настроек:
- Проверяет, что принтер в режиме ожидания и готов
- Резервирует запрошенное количество кодов из пула продукта
- Загружает данные кодов на принтер
- Загружает шаблон печати

Вы видите отметку рядом с каждым шагом по мере его выполнения. Если что-то пойдёт не так, вы получите понятное сообщение об ошибке с кнопкой **Повторить**.

6. Когда подготовка завершена, нажмите **Начать печать** для немедленного начала или **Перейти к заданию** для предварительного просмотра.

### Наблюдение за прогрессом

**На Панели управления:**

Отображаются только принтеры, у которых было хотя бы одно задание. Каждый отображается в виде карточки:

```
┌─────────────────────────────────────────────────────────────┐
│  Линия 1  192.168.1.100                        ● ПЕЧАТЬ     │
│  Задание #47: Яблочный 0.5л   342/500 (68%)                 │
│  ████████████████████░░░░░░░░░         [Пауза] [Отмена]     │
└─────────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────────┐
│  Линия 2  192.168.1.101                       ● ОЖИДАНИЕ    │
│  Задание #48: Вода 0.5л   0/1000                             │
│  Подготовлено, ожидание запуска   [Начать печать] [Отмена]   │
└─────────────────────────────────────────────────────────────┘
```

Карточки сортируются так, что активные задания отображаются первыми: печать, затем ошибки, затем пауза, затем готовые. Завершённые задания отображаются последними. Внутри каждой группы наиболее недавно обновлённое задание отображается сверху.

Нажмите на любую карточку, чтобы перейти на страницу **Задания** с выбранным заданием.

Под карточками принтеров на Панели управления отображается лента **Последние действия** — хронологический список недавних событий (импорты, запуски заданий, завершения, отмены, оповещения). Каждая запись выделена цветом по типу.

**На странице Задания (вкладка «Активные задания»):**

Выберите задание из списка, чтобы увидеть полные данные:
- Информация о продукте и принтере
- Контрольный список подготовки
- Значения счётчиков в реальном времени
- Шкала прогресса с точными числами

### Приостановка и возобновление

Во время печати вы можете нажать **Пауза**, чтобы временно остановить задание. Принтер останавливается, весь прогресс сохраняется.

Чтобы продолжить, нажмите **Продолжить**. Приложение повторно загрузит оставшиеся коды и продолжит с того места, где остановилось.

**Когда ставить на паузу:**
- Нужно что-то поправить на производственной линии
- Хотите проверить принтер перед продолжением
- Нужно загрузить расходные материалы

Пауза безопасна — ни один код не теряется и не расходуется впустую.

### Отмена задания

Вы можете отменить задание в любой момент, нажав **Отмена**. Вот что произойдёт:

- Коды, подтверждённые как напечатанные, остаются в статусе **Напечатано** (они были физически нанесены)
- Оставшиеся ненапечатанные коды возвращаются в статус **Доступно** (их можно использовать в будущих заданиях)
- Если для принтера настроен запас карантина, небольшое количество граничных кодов может быть помечено как **На карантине** для безопасности (см. [Карантинные коды](#карантинные-коды))

Отмена безопасна. Вы не теряете коды без необходимости.

### История заданий

Вкладка **История заданий** на странице Задания показывает все прошлые задания:

```

│  [Активные задания]  [История заданий]                       │
│                                                             │
│  Фильтры:  [Все принтеры ▼]  [Все продукты ▼]              │
│                                                             │
│  #   Продукт          Принтер  Кол-во  Статус     Дата     │
│  48  Апельсин. 0.33л  Линия 2  2000    ✅ Завершено  10 сен │
│  47  Яблочный 0.5л    Линия 1  500     ✅ Завершено  10 сен │
│  46  Яблочный 0.5л    Линия 1  500     ⛔ Отменено   9 сен  │
│  45  Вода 0.5л        Линия 3  1000    ✅ Завершено  9 сен  │
└─────────────────────────────────────────────────────────────┘
```

Нажмите на любую строку, чтобы увидеть полную информацию: количество напечатанных кодов, длительность и результат. Используйте фильтры для отображения заданий конкретного принтера или продукта.

## Страница 4: Управление кодами

### Статусы кодов

Каждый код в системе имеет статус. Вот что означает каждый из них:

| Статус | Значение |
|--------|----------|
| **Доступно** | Готов к использованию в задании печати. |
| **Зарезервировано** | Назначен активному заданию. Вы не можете изменять или перемещать зарезервированные коды. |
| **Напечатано** | Подтверждено, что физически напечатан на продукте. Не может быть использован повторно. |
| **Возвращено** | Был зарезервирован для задания, которое было отменено до печати этого кода. Код снова доступен. |
| **Списано** | Окончательно списан. Оператор подтвердил, что этот код никогда не должен использоваться (например, после расследования сбоя печати). |
| **На карантине** | Приложение не уверено, был ли этот код физически напечатан. Заморожен до вашего расследования. См. [Карантинные коды](#карантинные-коды). |

### Вкладка «Коды»

На странице **Продукция** выберите продукт и нажмите вкладку **Коды**, чтобы увидеть все его коды:

```
┌─────────────────────────────────────────────────────────────┐
│  [Операции]  [Настройки]  [Коды]                             │
│                                                             │
│  Статус: [Все ▼]    Поиск: [____________]                   │
│                                                             │
│  ☐  Текст кода             Статус        Партия  Задание   │
│  ☐  010460043993857221...  Доступно      batch1  —         │
│  ☐  010460043993857221...  Напечатано    batch1  #47       │
│  ☐  010460043993857221...  На карантине  batch1  #46       │
│                                                             │
│  Страница 1 из 100  (10 000 всего)   Показать: [100 ▼]     │
│  [Назад] [Далее]                                           │
│                                                             │
│  Действия над выбранными (0):                              │
│  Изменить на: [Доступно ▼] [Применить]                     │
│  Переместить в: [Выберите продукт ▼] [Переместить]         │
│  [Архивировать выбранные]                                  │
│  [Отменить]                                                │
└─────────────────────────────────────────────────────────────┘
```

**Фильтрация:** Используйте выпадающий список **Статус** для отображения кодов с определённым статусом. Используйте поле **Поиск** для поиска конкретного кода по тексту.

**Выбор кодов:** Отметьте галочками отдельные коды или используйте **Выбрать все** / **Снять выделение**. Зарезервированные коды (назначенные активным заданиям) всегда защищены и не могут быть выбраны.

### Изменение статуса кода

Выберите один или несколько кодов и используйте выпадающий список **Изменить на** для смены статуса.

Типичные причины для изменения статуса:
- **На карантине → Доступно** — после проверки вы убедились, что код НЕ был напечатан
- **На карантине → Списано** — после проверки вы убедились, что код БЫЛ напечатан или повреждён
- **Напечатано → Списано** — печать оказалась бракованной, продукт утилизирован

> **Внимание:** Изменение статуса кода с **Напечатано** или **Списано** обратно на **Доступно** означает, что он может быть напечатан повторно. Если код уже физически нанесён на продукт, это создаст дубликат — что является нарушением. Приложение предупредит вас перед выполнением такой операции.

### Перемещение кодов

Выберите коды и используйте выпадающий список **Переместить в** для переноса их в другой продукт или в нераспределённый пул. Это полезно, когда:
- Вы импортировали коды не в тот продукт
- Вы реорганизуете структуру продуктов
- Вы хотите перераспределить коды между продуктами

### Архивация кодов

Выберите коды и нажмите **Архивировать выбранные**, чтобы удалить их из активного пула. Архивированные коды:
- Удаляются из пула кодов продукта
- Их история сохраняется в архиве
- Текст кода освобождается для повторного импорта при необходимости

### Отмена действия

Нажмите **Отменить**, чтобы отменить последнюю операцию с кодами (изменение статуса, перемещение или архивацию). Приложение проверяет, безопасна ли отмена — например, отмена блокируется, если последующее задание печати уже использовало затронутые коды.

### Массовые операции

В нижней части вкладки «Коды» вы можете выполнять операции над **всеми кодами, соответствующими текущему фильтру**, а не только над теми, что на текущей странице:

- **Изменить все на...** — изменить статус всех отфильтрованных кодов
- **Переместить все в...** — переместить все отфильтрованные коды в другой продукт
- **Архивировать все** — архивировать все отфильтрованные коды

Это мощные операции. Приложение запросит подтверждение перед выполнением.

### Экспорт кодов

Нажмите **Экспорт CSV**, чтобы скачать все коды, соответствующие текущему фильтру, в виде CSV-файла. Это полезно для ведения учёта или передачи списков кодов в другие системы.

### Нераспределённые коды

Иногда коды существуют без привязки к какому-либо продукту. Это происходит, когда:
- Продукт был удалён, и вы выбрали сохранить его коды
- Коды были явно перемещены в нераспределённый пул

Нераспределённые коды отображаются в специальном разделе под деревом продуктов на странице «Продукция». Нажмите на него, чтобы управлять ими — вы можете переместить их в продукт или архивировать.

### Удаление продукта

При удалении продукта, который всё ещё содержит коды:

- Если у продукта есть **активные задания или зарезервированные коды**, удаление блокируется. Сначала отмените задания.
- В остальных случаях вам предлагается выбор:
  - **Да (Сохранить коды)** — коды перемещаются в нераспределённый пул. Вы сможете перераспределить их позже.
  - **Нет (Удалить коды тоже)** — коды архивируются. Их текст становится доступным для повторного импорта.
  - **Отмена** — ничего не происходит.

Чтобы удалить продукт: перейдите на вкладку **Настройки** и нажмите **Удалить продукт** в разделе «Опасная зона».

## Страница 5: Управление принтерами

### Подключение и отключение

Приложение подключается ко всем принтерам автоматически при запуске.

**Чтобы вручную отключить принтер:**
1. Перейдите на страницу **Принтеры**
2. Выберите принтер
3. Нажмите **Отключить**

> **Важно:** Если у принтера есть активное задание печати, отключение переведёт задание в статус **Отключён**. Это означает, что состояние принтера неизвестно — приложение не может определить, продолжил ли принтер печать после отключения. Вам нужно будет переподключиться и явно возобновить или отменить задание. См. [Отключение принтера во время печати](#отключение-принтера-во-время-печати).

**Чтобы переподключиться:** Нажмите **Подключить**. Приложение восстановит соединение. Если было отключённое задание, вы сможете возобновить или отменить его на странице «Задания».

### Конфигурация

Вкладка **Конфигурация** показывает настройки принтера и позволяет их изменять:

- **Имя** — отображаемое название, используемое во всём приложении
- **IP-адрес** — сетевой адрес принтера
- **Порт** — TCP-порт (по умолчанию 9100)
- **Запас карантина** — сколько граничных кодов помещать в карантин при отмене задания во время печати (по умолчанию 0; значение 1 — максимальная безопасность для ценных кодов)

Чтобы изменить настройку, нажмите **Редактировать**, измените значения и нажмите **Сохранить**. Приложение переподключится автоматически при изменении IP-адреса или порта.

### Управление хранилищем

Вкладка **Хранилище** показывает файлы, хранящиеся на принтере:


- Файлы с пометкой **Используется** привязаны к продукту — они защищены и не могут быть удалены
- Файлы с пометкой **Не привязано** — осиротевшие — их можно безопасно удалить, они уже выбраны для очистки

### Проверка

Вкладка **Проверка** позволяет проверить, соответствует ли состояние принтера ожиданиям приложения:

1. Выберите принтер
2. Нажмите **Запустить проверку**

Приложение проверяет:
- **Соединение** — доступен ли принтер?
- **CSV-файл** — присутствует ли ожидаемый файл данных на принтере?
- **Активный шаблон** — загружен ли правильный шаблон?
- **Счётчики** — совпадают ли счётчики принтера с записями приложения?
- **Статус принтера** — в исправном ли состоянии принтер?

Результаты выделены цветом:
- **Пройдено** (зелёный) — всё совпадает
- **Предупреждение** (жёлтый) — есть расхождение, но не обязательно проблема
- **Ошибка** (красный) — несоответствие, требующее внимания

## Страница 6: Решение проблем

Code Print Manager спроектирован для безопасной обработки сбоев. Основной принцип: **если есть хоть какая-то неопределённость в том, был ли код напечатан, приложение помечает его как использованный, а не рискует дубликатом.** Потеря кода допустима; его дублирование — нет.

### Отключение принтера во время печати

**Что происходит автоматически:**
- Задание переходит в статус **Отключён**
- Приложение сохраняет весь подтверждённый прогресс
- Появляется уведомление с указанием, какой принтер и задание затронуты
- Другие принтеры и их задания продолжают работать нормально — они полностью независимы

**Что вы видите:**

```
┌─────────────────────────────────────────────────────────────┐
│  Линия 1  192.168.1.100                      ● ОТКЛЮЧЁН     │
│  Задание #47: Яблочный 0.5л  342/500                         │
│  Отключён на 342/500 — подключите принтер для продолжения    │
└─────────────────────────────────────────────────────────────┘

УВЕДОМЛЕНИЯ
  ⚠ Линия 1: Принтер отключён. Задание #47 переведено в статус «Отключён».
```

**Что делать:**

1. Устраните проблему с подключением (проверьте кабели, сеть, питание принтера)
2. Перейдите на страницу **Принтеры** и нажмите **Подключить**
3. Перейдите на страницу **Задания** и выберите отключённое задание
4. Выберите:
   - **Продолжить** — приложение проверит принтер, сверит счётчики, повторно загрузит оставшиеся коды и продолжит печать
   - **Отмена** — безопасно завершает задание, помещая неопределённые коды в карантин

> **Важно:** Приложение не возобновляет отключённое задание автоматически. Поскольку состояние принтера после отключения неизвестно (он мог продолжить печать, или кто-то мог использовать его для другой задачи), вы должны явно выбрать действие.

### Сбой питания или аварийное завершение

Весь прогресс непрерывно сохраняется в базу данных. Ничего не теряется.

**Когда вы перезапускаете приложение после неожиданного завершения:**

Если в момент остановки были активные задания, вы увидите экран **Восстановления**:

- Каждое прерванное задание отображается с:
  - Количеством кодов, подтверждённых приложением как напечатанные
  - Количеством кодов, фактически напечатанных принтером (считано из постоянного счётчика принтера)
  - Расхождением между этими двумя значениями

Вы можете выбрать для каждого задания:
- **Продолжить** — продолжить с того места, где остановилось
- **Отмена** — безопасно завершить задание

**Общий счётчик** принтера никогда не сбрасывается, даже после отключения питания. Приложение использует его для точного определения того, что произошло во время его отсутствия.

### Неожиданные скачки счётчика

Если кто-то печатает через сенсорный экран принтера или через другую систему (не через данное приложение), приложение обнаруживает неожиданное увеличение счётчика.

**Что вы видите:**
- Жёлтое уведомление: «Неожиданный скачок счётчика (+N)»
- Затронутые коды помечены как использованные в целях безопасности

**Что делать:**
- Проверьте, не печатал ли кто-то напрямую через принтер
- Если дополнительная печать была намеренной (например, тест), вы можете управлять затронутыми кодами на вкладке «Коды»
- Если никто не использовал принтер, требуется дальнейшее расследование — это может указывать на аппаратную проблему

### Карантинные коды

Коды помещаются в карантин, когда приложение не может быть уверено, были ли они физически напечатаны. Это происходит в ситуациях:

- Сбой питания во время печати (некоторые коды могли быть напечатаны между последним обновлением прогресса и сбоем)
- Отмена задания, когда принтер мог напечатать дополнительные коды после последнего подтверждённого значения
- Отключение принтера, когда его состояние неизвестно

**Карантинные коды заморожены** — они не могут быть автоматически использованы в новом задании. Это предотвращает случайные дубликаты.

**Как разрешить карантинные коды:**

1. Перейдите в **Продукция** > выберите продукт > вкладка **Коды**
2. Отфильтруйте по статусу: **На карантине**
3. Расследуйте каждый код:
   - Проверьте физические продукты на производственной линии
   - Определите, был ли код фактически напечатан
4. Для каждого кода измените статус:
   - **Доступно** — если вы убедились, что он НЕ был напечатан (его можно использовать повторно)
   - **Списано** — если вы убедились, что он БЫЛ напечатан или иным образом непригоден

> **Совет:** Вы можете выбрать несколько карантинных кодов и изменить их все сразу, если у них одинаковый результат проверки.

### Продолжительные сбои

Если принтер продолжает давать сбои (потеря соединения, ошибки ввода-вывода), приложение эскалирует ситуацию:

1. Оно продолжает автоматические попытки
2. После множества последовательных сбоев приложение прекращает попытки и переводит задание в статус **Ошибка**
3. Все неподтверждённые коды помещаются в карантин
4. Вы получаете красное уведомление

Для восстановления после задания с ошибкой — отмените его и создайте новое. Карантинные коды необходимо разрешить на вкладке «Коды».

## Страница 7: Часто задаваемые вопросы

### Начало работы

**Нужно ли устанавливать .NET или другое ПО?**

Нет. Code Print Manager — самодостаточное приложение. Всё необходимое включено в папку. Просто скопируйте и запустите.

**Можно ли запускать приложение на нескольких компьютерах?**

Приложение рассчитано на работу на одном компьютере, подключённом ко всем принтерам. Запуск на нескольких компьютерах для одних и тех же принтеров не поддерживается и может вызвать конфликты.

**Как тестировать без реального принтера?**

Запустите приложение из командной строки с параметром `--mock`:
```
CodePrintManager.Desktop.exe --mock
```
Это включает режим имитации — вы можете добавлять принтеры и запускать задания без реального оборудования. Виртуальные принтеры имитируют процесс печати с настраиваемой задержкой.

**Каковы системные требования?**

Windows 10 или 11 (64-разрядная), 2 ГБ оперативной памяти, 500 МБ свободного места на диске и сетевое подключение к принтерам.

---

### Печать

**Сколько кодов можно напечатать в одном задании?**

Столько, сколько доступно в пуле кодов продукта. Приложение не устанавливает верхнего предела.

**Можно ли печатать на двух принтерах одновременно?**

Да. Каждый принтер работает независимо. Вы можете запустить отдельное задание на каждом принтере одновременно. Однако каждый принтер может иметь только одно активное задание, и каждый продукт — только одно активное задание.

**Что будет, если я закрою приложение во время печати?**

Принтер может продолжить печать короткое время после закрытия приложения. При перезапуске экран восстановления покажет прерванные задания и позволит сверить состояние. См. [Сбой питания или аварийное завершение](#сбой-питания-или-аварийное-завершение).

**Подготовка задания не удалась — что делать?**

Прочитайте сообщение об ошибке — оно точно указывает, что пошло не так. Частые причины:
- Принтер не в режиме ожидания (кто-то другой его использует, или он остался в состоянии печати)
- Принтер отключён или не в сети
- Недостаточно доступных кодов в пуле продукта
- Файл шаблона отсутствует на вашем компьютере

Устраните проблему и нажмите **Повторить**.

**Можно ли изменить количество после подготовки задания?**

Нет. Чтобы напечатать другое количество, отмените текущее задание и создайте новое с нужным количеством.

---

### Коды

**Что означает «На карантине»?**

Приложение не уверено, был ли этот код физически напечатан на продукте. Он заморожен для предотвращения случайного повторного использования. Вам нужно расследовать и решить: он был напечатан (изменить на «Списано») или нет (изменить на «Доступно»). См. [Карантинные коды](#карантинные-коды).

**Можно ли повторно использовать напечатанный код?**

Технически да — вы можете изменить статус «Напечатано» на «Доступно» на вкладке «Коды». Но приложение настоятельно предупреждает, потому что это опасно. Если код уже физически нанесён на продукт, повторное использование создаёт незаконный дубликат. Делайте это только если вы абсолютно уверены, что оригинальный продукт был уничтожен.

**Я импортировал коды, но количество «Доступно» не изменилось — почему?**

Проверьте отчёт об импорте. Наиболее вероятная причина — все коды были отклонены как дубликаты, они уже существуют в системе в другом продукте или в том же продукте.

**Как узнать, какие коды привязаны к какому продукту?**

Перейдите в **Продукция**, выберите продукт и нажмите вкладку **Коды**. Вы увидите все коды, принадлежащие этому продукту. Для поиска конкретного кода используйте поле «Поиск».

**Что происходит с кодами при удалении продукта?**

Вам предлагается выбор: сохранить коды (они переместятся в нераспределённый пул) или удалить их тоже (они будут архивированы). В любом случае ни один код не теряется бесследно.

---

### Принтеры

**Принтер показывает «Не в сети» — что делать?**

1. Проверьте, что принтер включён
2. Проверьте сетевой кабель/подключение
3. Убедитесь, что IP-адрес правильный (Принтеры > вкладка «Конфигурация»)
4. Попробуйте выполнить ping из командной строки: `ping 192.168.1.100`
5. Проверьте настройки брандмауэра

Приложение автоматически повторяет попытки подключения в фоновом режиме. Как только принтер станет доступен, соединение восстановится автоматически.

**Можно ли удалить принтер, у которого есть история заданий?**

Вы можете удалить принтер, только если у него нет активных заданий. История прошлых заданий сохраняется даже после удаления принтера.

**Что такое настройка «Запас карантина»?**

При отмене задания во время печати может быть небольшое количество кодов на границе между «подтверждённо напечатанные» и «ещё не напечатанные», статус которых неопределён. Запас карантина определяет, сколько таких граничных кодов будет помечено как «На карантине» вместо возврата в «Доступно». Значение по умолчанию — 0 (без запаса карантина). Значение 1 — наиболее безопасный вариант для ценных кодов.

См. [Конфигурация](#конфигурация) для изменения этой настройки.

---

### Проблемы

**Приложение показывает экран восстановления при запуске — что произошло?**

Приложение обнаружило задания, которые были активны, когда оно в последний раз было неожиданно закрыто (сбой, отключение питания, принудительное закрытие). Экран восстановления позволяет проверить каждое задание, сравнить ваши записи с фактическими счётчиками принтера и решить, продолжить или отменить каждое из них. См. [Сбой питания или аварийное завершение](#сбой-питания-или-аварийное-завершение).

**Я вижу «Неожиданный скачок счётчика» — это серьёзно?**

Это означает, что счётчик принтера увеличился больше, чем ожидалось, между двумя проверками. Обычно это значит, что кто-то печатал напрямую через принтер (через его сенсорный экран или другое приложение). Выясните, что произошло. Приложение уже пометило затронутые коды в целях безопасности.

**Принтер отключился, и задание показывает статус «Отключён» — что делать?**

1. Устраните проблему с подключением принтера
2. Переподключитесь (Принтеры > Подключить)
3. Перейдите в «Задания» и возобновите или отмените отключённое задание

Приложение не возобновляет задание автоматически, потому что состояние принтера неизвестно. См. [Отключение принтера во время печати](#отключение-принтера-во-время-печати).

**Приложение не запускается**

- Убедитесь, что у вас Windows 10 или 11 (64-разрядная)
- Попробуйте запустить от имени администратора (правой кнопкой мыши > «Запуск от имени администратора»)
- Проверьте папку `logs/` в каталоге приложения на наличие ошибок

**Ошибка «База данных заблокирована»**

- Убедитесь, что запущен только один экземпляр приложения
- Полностью закройте приложение
- Удалите файлы `codeprintmanager.db-shm` и `codeprintmanager.db-wal` (основной файл `.db` можно оставить)
- Перезапустите приложение

**Где находятся файлы журналов?**

В папке `logs/` внутри каталога приложения. Файлы журналов организованы по дате. Отправляйте последний файл журнала при обращении в поддержку.
